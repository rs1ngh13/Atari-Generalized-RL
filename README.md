# Atari-Generalized-RL

Most reinforcement learning (RL) agents are trained on a single game, making them highly specialized and unable to leverage shared knowledge across similar environments. This project seeks to develop a generalized RL model that is jointly trained on a small subset of Atari games (e.g., Pong and Breakout) using transformer-based architectures and standard RL algorithms (DQN, PPO, A2C). The aim is to learn transferable representations that enable the agent to exhibit reasonable zero-shot performance and rapid fine-tuning on a new, unseen Atari game
